# SistemaExpedientes-LimaNorte
Sistema de registro de expedientes en c# windows Forms-Municipalidad Lima Norte
## Descripción
Sistema desarrollado para la Municipalidad de Lima Norte para el registro, validación y control de expedientes administrativos.

## Funcionalidades principales
- Registro: Código, DNI, Nombres, Tipo, Asunto, Fecha
- Validación de datos obligatorios
- Búsqueda secuencial para detectar código duplicado
- Validación DNI: 8 dígitos numéricos
- Guardado en Expedientes.txt
- Visualización en DataGridView

## Tecnologías
- C# Windows Forms (.NET)
- Visual Studio 2022
- GitHub para control de versiones

## Diagrama de flujo
Algoritmo Registrar Expediente con 3 validaciones y retorno a ingreso de datos en caso de error.
